# Week 09 — Code agents и безопасные инструменты

## Результат недели

Участник понимает цикл prompt -> code/tool -> execution -> answer и улучшает один агентный инструмент или ограничение.

## Зачем это проекту

Агент полезен, только если его действия наблюдаемы, ограничены и воспроизводимы. Автоматизация не снимает ответственность с автора результата.

## Практика

- изучите `src/scireason/agentic/` и `docs/smolagents.md`;
- сравните internal backend и `smolagents` в mock-режиме;
- добавьте небольшой graph tool или validation guard;
- сохраните вход, действия и итоговый артефакт.

## Вклад по ролям

- **Исследователь:** задаёт задачу, где tool действительно нужен.
- **Эксперт:** проверяет итоговое объяснение.
- **Разработчик:** реализует tool/sandbox rule и тест.
- **Координатор:** документирует безопасный сценарий.

## Готово, когда

Агент не требует скрытой среды, ошибка обрабатывается понятно, а результат можно проверить без доверия к модели.
