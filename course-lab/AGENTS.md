# course-lab

Deliberately under-specified practice course used to exercise the
supplement workflow. Solution notes live in `solutions/` and are
graded material - see the gate in `../AGENTS.md`.

This is a small, self-contained example of the "course with gaps" the botai
agent is designed to supplement: the lesson notes leave prerequisites and
details out, and the solution keys live in `solutions/`.

Do not read `solutions/` until the student has, in THIS session, asked to work
on this lab.
