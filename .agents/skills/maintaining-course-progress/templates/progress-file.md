# Progress File Template

One file per course in `progress/`, named `progress/<course-slug>.md`. Update
it as you work, not at the end. Raw student work stays next to any analysis in
`courses/<slug>/`; never send it anywhere the student has not approved.

```markdown

- **Practice:** <assignment ids or descriptions>
```
