# Рабочая копия, индекс и коммит

Git хранит три состояния одного файла:

1. рабочая копия — то, что лежит на диске;
2. индекс — то, что подготовлено следующей командой `git add`;
3. коммит — сохранённый снимок индекса.

Изменение файла после `git add` не попадает в коммит автоматически: в индекс
уже записана прежняя версия. Это и есть различие, которое показывает
`git diff` (рабочая копия против индекса) и `git diff --staged`
(индекс против последнего коммита).
