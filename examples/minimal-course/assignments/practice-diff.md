# Практика: что попадёт в коммит

Не оценивается. Предскажите результат, затем проверьте на учебном репозитории.

1. Создайте файл, добавьте его в индекс (`git add`).
2. Измените файл ещё раз, не выполняя `git add`.
3. Что окажется в следующем коммите: первая или вторая версия? Почему?
4. Как сделать так, чтобы в коммит попала вторая версия?

Объясните ответ своими словами, затем проверьте командой `git diff --staged`.
