# legacy-course — вход для тестов миграции v1 → v2

Фикстура описывает workspace в формате botai 1.x:

- `progress/python-101.md` — дневник в свободной Markdown-форме, два слушателя
  в одном файле, смесь структурированных записей и прозы;
- `courses/python-101/` — курс без `botai/course.json`.

Задача миграции — сохранить исходник целиком, извлечь только то, что
действительно написано, и пометить остальное как требующее проверки
человеком. Ни один факт не должен быть додуман: `mastered` из v1 не является
доказательством и импортируется как заявленное, а не проверенное состояние.
