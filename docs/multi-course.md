# Multi-course workspaces

botai поддерживает **одновременное прохождение нескольких курсов**: агент
работает в **отдельном проекте (workspace)**, а под каждый курс внутри
него создаётся **подпроект**. Никакого смешивания прогресса, соглашений и
правил между курсами.

## Модель

```
<workspace>/                    # один проект botai (make install DEST=<dir>)
├── AGENTS.md                   # политика (устанавливается только в проект)
├── courses/                    # подпроекты — по одному на курс
│   ├── history-of-science/
│   │   ├── README.md           # название курса
│   │   ├── syllabus.md         # модули, цели, пререквизиты
│   │   ├── lessons/            # материалы занятий
│   │   ├── assignments/        # задания (работа студента — здесь)
│   │   └── references/         # корпус, манифесты, источники
│   ├── philosophy-of-science/  # второй одновременный курс
│   └── ip-law/                 # третий одновременный курс
├── progress/
│   ├── history-of-science.md   # прогресс по курсу (отдельный файл)
│   ├── philosophy-of-science.md
│   ├── ip-law.md
│   └── _journal.md             # де-идентифицированный журнал по всем курсам
├── dist/                       # временные артефакты
└── .botai/
    └── active                  # маркер активного курса (имя без newline)
```

## Правила

1. **Один workspace = один проект.** `make install DEST=<dir>` создаёт
   отдельный проект и копирует политику/навыки только в него; ничего не
   пишется в глобальные конфиги. Запускай агента из корня этого проекта.
2. **Один подпроект на курс.** `make new-course NAME=<slug>` создаёт
   `courses/<slug>/`. Не клади два курса в одну папку и не веди занятия
   из корня репозитория.
3. **Состояние ключуется слагом курса.** Прогресс, согласие и предпочтение
   доставки, списки «оценочное/тренировочное» и дополнения принадлежат
   ровно одному курсу: `progress/<slug>.md`.
4. **Активный курс.** `make course-set COURSE=<slug>` записывает текущий
   курс в `.botai/active`; `make active` показывает его; `make courses`
   перечисляет все подпроекты с хвостиком прогресса. Если маркера нет —
   спросить студента, какой курс ведём; не угадывать.

## Типовой флоу

1. **Старт нового проекта:** `make install DEST=<workspace>`, затем
   `make new-course NAME=<slug>` для каждого курса.
2. **Возобновление:** `make active` или `make courses` → подтвердить курс
   со студентом.
3. **Занятие:** прочитать `courses/<slug>/syllabus.md` и
   `progress/<slug>.md`, вести занятие по правилам AGENTS.md (внутри
   модуля, дополнения помечены), по завершении дополнить
   `progress/<slug>.md` и одну де-идентифицированную строку в
   `progress/_journal.md`.
4. **Переключение:** студент может сменить курс — `make course-set
   COURSE=<slug>`, перечитать скоуп и прогресс нового курса, явно
   объявить переключение.

## Антиутечки

- Дополнение/пример, сделанные для курса A, не выдавать за материал
  курса B — проверить по программе B или пометить как внешнее.
- Согласие и предпочтение доставки — пер-курсовые и могут различаться.
- Правила «оценочное vs тренировочное» — пер-курсовые.
- Общую тему двух курсов преподавать по материалу активного курса, не
  сливая программы.

## Команды

```bash
make install DEST=<workspace>       # создать новый workspace
make new-course NAME=<slug>         # создать подпроект курса
make courses                        # список курсов + статус прогресса
make course-set COURSE=<slug>       # переключить активный курс
make active                         # показать активный курс
make progress COURSE=<slug>         # сводка прогресса по курсу
```

Полная процедура агента — навык `multi-course-workspace`
(`.agents/skills/multi-course-workspace/SKILL.md`).
