# Корпус и источники

Документ описывает, как курс получает корпус, почему это сделано декларативно
и что именно проверяется. Он же — граница обещаний: здесь сказано, чего слой
**не** делает.

## Зачем декларативный манифест

В версии 1 обвязка запускала Python-скрипт, который приезжал **вместе с
курсом** (`install.py` вызывал course-side fetcher). Это переворачивает
отношение доверия: то, что проверяют, само решает, как его проверять. Курс мог
скачать что угодно и назвать это корпусом.

Здесь наоборот: манифест — это **данные** (`botai/corpus-manifest.json`), а
загрузчик наш. Правила ниже обеспечивает код, который установил
обучающийся, а не код, который приложил автор курса.

## Манифест

```json
{
  "schema_version": 2,
  "corpus_id": "history-of-science",
  "version": "3",
  "source_revision": "2026-01-release",
  "artifacts": [
    {
      "artifact_id": "texts",
      "url": "https://example.org/corpus-texts-v3.zip",
      "sha256": "…64 hex…",
      "media_type": "application/zip",
      "unpack": "zip",
      "compressed_bytes": 18432000,
      "unpacked_bytes_max": 96000000,
      "auth_required": false
    }
  ],
  "files": [
    {
      "path": "txt/article-01.txt",
      "sha256": "…64 hex…",
      "byte_size": 48120,
      "role": "text",
      "artifact_id": "texts"
    }
  ],
  "index": {
    "kind": "text",
    "config_path": null,
    "chunks_path": null,
    "text_mapping_path": null,
    "embedding_model_id": null,
    "embedding_revision": null
  }
}
```

`index.kind` принимает `none`, `text` или `annoy`. Важно: **`none` — это
нормальное значение, а не деградация**. Курс без индекса просто ищется по
тексту, и ответ честно сообщает `retrieval_method: text`, а не делает вид,
что нашёл семантически близкое.

Ссылки на файлы (`files[]`) обязательны и проверяются **поштучно**. Хеш архива
доказывает архив, а не то, что файл, на который ссылается индекс, — тот самый.

## Команды

```bash
# Что с корпусом этого курса
python scripts/cli.py corpus-status --course <slug>

# Скачать, распаковать, проверить
python scripts/cli.py corpus-acquire --course <slug>

# Предпросмотр (ничего не пишется) и офлайн-режим
python scripts/cli.py corpus-acquire --course <slug> --dry-run
python scripts/cli.py corpus-acquire --course <slug> --offline

# Поиск по принятым материалам
python scripts/cli.py source-search --course <slug> --query "теорема Байеса"

# Проверка цитаты
python scripts/cli.py quote-verify --course <slug> --citation citation.json
```

### Состояния готовности

| Состояние | Что означает |
|---|---|
| `not_required` | манифест объявлен и не содержит артефактов — проверять нечего |
| `missing` | манифест не задан, или корпус не установлен |
| `ready` | конкретный принятый манифест проверен **по каждому файлу** |
| `unverified` | файлы на месте, но хешей в манифесте нет |
| `stale` | файлы разошлись с манифестом |
| `failed` | установка не удалась |

`missing` при отсутствующем манифесте — намеренно: «не смотрели» и «смотреть
нечего» — разные факты, и успокаивает только второй.

## Что именно проверяется

### URL

Манифест задаёт адрес; загрузчик решает, можно ли туда идти. Отказывает:

- не `https` — по `http` содержимое подменяется по пути;
- логин или токен внутри URL — секреты не живут в манифесте;
- `localhost`, loopback, приватные диапазоны (`10/8`, `192.168/16`,
  `172.16/12`), link-local (`169.254/16`);
- адреса служб метаданных (`169.254.169.254`,
  `metadata.google.internal`) — классический способ вычитать учётные данные
  машины через «скачай этот PDF»;
- неразрешимые имена: неизвестный адрес — не безопасный, а неизвестный.

Проверяется **каждый redirect**, а не только исходный адрес: публичная ссылка,
которая перенаправляет во внутреннюю сеть, — обычный приём.

### Архив

- выход за каталог (`..`, абсолютные пути) — отказ;
- симлинки и специальные файлы — отказ: для текстового корпуса они не нужны,
  а следить за ссылкой означает писать за пределы каталога;
- **лимиты соблюдаются во время записи**, а не по заголовкам: zip-бомба врёт
  именно в заголовках. По умолчанию 2 ГиБ сжатого, 10 ГиБ распакованного,
  100 000 файлов;
- имена, различающиеся только регистром, отклоняются: на Windows они
  перезаписывают друг друга, и корпус перестаёт совпадать с манифестом.

### Несовпадение хеша

**Жёсткая остановка, не предупреждение.** Это значит, что артефакт повреждён
или источник изменился после публикации манифеста. Продолжать — значит
приписать автору байты, которых он не публиковал.

### Установка

Скачивание идёт в staging, распаковка — с лимитами, проверка — по каждому
файлу, и только потом каталог занимает своё место. **Неудачное обновление не
трогает ранее установленный корпус**: терять рабочие источники из-за сбоя
загрузки незачем.

## Область поиска

Область вычисляется **до** поиска: список разрешённых файлов строится один раз,
и исключения применяются на этом шаге. Путь под исключённым корнем не попадает
в набор кандидатов вообще, поэтому его нельзя вернуть и «отфильтровать потом».

```
область     : minimal-diff (файлов 3, снимок принятой ревизии)
исключено   : teacher
способ      : text
```

Корпус каждого курса живёт в `.botai/corpus/<course-id>/`. В версии 1 корень
был общим, и «корпус установлен» могло быть правдой про другой курс.

## Проверка цитаты

```bash
python scripts/cli.py quote-verify --course minimal-diff --citation cite.json
```

```json
{
  "source_ref": {
    "path": "lessons/01-working-tree.md",
    "locator": {"lines": {"start": 11, "end": 11}}
  },
  "verbatim": "`git diff` (рабочая копия против индекса) и `git diff --staged`"
}
```

Возможные статусы:

| `quote_status` | Смысл |
|---|---|
| `exact` | точное вхождение в указанном фрагменте |
| `normalized_match` | совпадение после NFKC и схлопывания пробелов — **слабее** точного, и это сообщается |
| `mismatch` | текст не найден, или найден в другом месте файла |
| `unverifiable` | проверить нечем: координаты PDF/chunk/ячейки, путь вне материалов, диапазон за концом файла |

Отдельно проверяются **координаты**. Текст в том же файле, но не в указанном
фрагменте, — это `mismatch` с пояснением «ошибка координат, а не цитаты».
Молча подправить локатор означало бы уничтожить свидетельство того, что
модель выдала неверную ссылку.

Диапазон строк за концом файла **не подгоняется**: это `unverifiable`, а не
«обрежем до последней строки».

## Что этот слой не делает

- **Не проверяет смысл.** `quote_status` описывает совпадение строки;
  `support_status` всегда `not_checked`. Точная цитата не доказывает
  утверждение, которое из неё сделали. Это разные поля именно для того, чтобы
  первое не читалось как второе.
- **Не читает PDF, ноутбуки и chunk-индексы.** Для них честный ответ
  `unverifiable`. Делать вид, что страница PDF проверена, не имея парсера,
  было бы ложью.
- **Не переводит корпус.** Перевод делается при показе студенту, а не в
  хранилище: перезапись файлов корпуса сломала бы индекс, проверку цитат и
  запись о происхождении.
- **Не запускает код курса.** Никакого course-side fetcher в стандартном пути.
- **Не выполняет семантический поиск.** `annoy` объявлен в схеме, но
  обязательной тяжёлой зависимости нет: отсутствие модели эмбеддингов меняет
  `retrieval_method`, а не ломает обучение.

## Legacy-манифесты

Манифест v1 (`index-manifest.json`, `corpus-manifest.json`) распознаётся
адаптером, который переносит **только те поля, которые понимает однозначно**.
Всё остальное даёт `LEGACY_MANIFEST_UNSUPPORTED` с просьбой к автору, а не
запуск загрузки наугад. Преобразованный манифест помечается
`legacy_adapted`, и статус готовности не может стать `ready`, если хешей в нём
не было: у адаптера нет права выдать непроверенное за проверенное.
