Set up the course workspace and check the environment.

1. Run `make setup` to create the workspace layout (courses/, progress/, dist/).
2. Run `make doctor` to see the detected environment.
3. Report what was created and what the next steps are (scaffold a course with
   `make new-course NAME=<slug>` or start a session with /session).

Do not create course content that was not requested.
